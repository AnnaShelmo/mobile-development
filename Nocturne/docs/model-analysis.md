# Анализ моделей TensorFlow Lite для распознавания изображений

## Задача

На экране «Сканер» пользователь выбирает фотографию из галереи, приложение
обрабатывает её локально обученной моделью и показывает наиболее вероятный
класс объекта и три лучших варианта с вероятностями.

## Критерии выбора модели

- работа на обычном телефоне без GPU и без интернета;
- небольшой размер файла модели;
- достаточная точность на фотографиях архитектуры (соборы, замки, дворцы);
- поддержка стандартным TensorFlow Lite без облачных сервисов.

## Рассмотренные варианты

| Модель | Параметры | Размер float32 | Размер int8 | Top-1 ImageNet | Комментарий |
|---|---:|---:|---:|---:|---|
| MobileNetV1 1.0 224 | ~4.2 млн | ~16.9 МБ | ~4.2 МБ | ~70.6% | простая и быстрая, много примеров |
| MobileNetV2 1.0 224 | ~3.5 млн | ~14 МБ | ~3.5 МБ | ~71.8% | хороший базовый вариант |
| MobileNetV3 Small 224 | ~2.5 млн | ~9.8 МБ | ~2.5 МБ | ~67.4% | самая лёгкая, но менее точная |
| **EfficientNet-Lite0 224** | **~4.7 млн** | **~18.6 МБ** | **~5.4 МБ** | **~75.1%** | **выбрана для проекта** |
| EfficientNet-Lite1 224 | ~5.4 млн | ~21 МБ | ~5.4 МБ | ~76.7% | точнее, но медленнее |
| ML Kit Image Labeling | — | — | — | — | готовая обёртка Google, модель скрыта внутри зависимости |

## Почему выбрана EfficientNet-Lite0

1. Это мобильная версия EfficientNet, оптимизированная под процессор телефона.
2. Точность около 75% выше, чем у MobileNetV2 (~72%), при сопоставимом размере
   квантованной модели.
3. Вход 224×224 и 1000 классов ImageNet — стандартный формат, который напрямую
   поддерживается TensorFlow Lite Task Library.
4. В ImageNet есть нужные для Nocturne классы: `church`, `monastery`, `castle`,
   `palace`, `dome`, `bell cote`, `altar`, `lighthouse`, `mosque`, `stupa`,
   `fountain`, `viaduct`, `triumphal arch`.
5. Модель работает полностью локально: интернет нужен только для загрузки фото
   места в каталоге, но не для самого распознавания.

Для проекта взята квантованная версия `int8` размером около 5.4 МБ: она заметно
меньше float32-версии (18.6 МБ) и быстрее работает на CPU, а потеря точности
небольшая.

## Как устроена работа сканера

1. Пользователь нажимает «Выбрать изображение»; открывается системная галерея
   через `ActivityResultContracts.GetContent()` — разрешения не нужны.
2. Фото уменьшается до разумного размера, чтобы не занять всю память.
3. Модель загружается из `app/src/main/assets/efficientnet_lite0.tflite` и
   запускается через `ImageClassifier` из TensorFlow Lite Task Library.
4. Task Library сама приводит изображение к 224×224 и переводит выходные
   значения в вероятности.
5. Приложение показывает лучший класс крупно и топ-3 классов с процентами;
   названия переводятся на русский через небольшой словарь, неизвестные классы
   выводятся как в ImageNet.

## Ограничения

- ImageNet не содержит класса «готический собор»: похожие объекты обычно
  распознаются как `church`, `monastery`, `palace` или `castle`.
- Модель универсальная и обучена на ImageNet, а не на местах Nocturne, поэтому
  на необычных ракурсах может ошибаться. Именно поэтому показывается топ-3,
  а не один категоричный ответ.
- Модель не заменяет каталог и не определяет конкретное место — она лишь
  подсказывает общую категорию объекта на фотографии.
